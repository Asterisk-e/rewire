Offline model setup

Install the browser runtime once, then put compatible model files under models/. The app disables remote model downloads. A first-time model setup requires obtaining the runtime and model files while online; inference itself runs locally.

Browser models and local speech processing run on this device. Local server models receive prompts only at the server URL you add. No third-party analytics, font services or cloud model endpoints are built into this app.
