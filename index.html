Model endpoint

The backend connects to an OpenAI-compatible API. Set MODEL_BASE_URL, MODEL_API_KEY and MODEL_NAME in backend/.env. PocketPal's exact server URL depends on the version and serving option you use.

Connection and privacy

Chat messages are sent to the backend URL above, then forwarded to the configured model endpoint. Do not connect to a backend you do not trust. The model API key stays in the backend environment file, not in this webpage. Do not expose an unauthenticated backend to the public internet.
